# v0.6.11

CLI 0.6.11 配套 boss-recruitment Skill 1.0.20，兼容标识 `2026-10-30-resume-analysis-v1`。安装时同步整个 Skill 目录并运行 `version-check --json`。

- 新增公开 `switch-job --list/--job`，复用会话锁和页面守卫；列出岗位后单次点击左侧安全空白收起菜单，点击前后核验页面、岗位及会话。
- 简历截图到底后不再向上恢复。沟通收集截图后点击左侧安全空白退出；推荐／搜索截图后保持打开，等待 Agent 结果。原有向下滚轮和随机停顿保持不变。
- `download-resume` 和 `probe-resume --download` 整条命令总时限改为30秒，包含定位、预览、下载及核验；其他附件命令保持15秒。
- Skill 明确文字优先、同人材料一次判断、按身份与哈希复用OCR、缩短输出、区分收集与筛选。新增离线交接脚本，由 Agent 提交字段和证据行号，脚本校验并展开原文保存，避免每份简历重写保存程序。

解析性能：同一已知模拟样本复用OCR后17.20秒；另一份不同内容的33行单栏模拟简历首次OCR到结构化收集结果保存10.941秒，其中OCR命令3.992秒、衔接0.101秒、解析及保存6.848秒。第二次未使用历史OCR或解析结果，33行经Unicode规范化与去空白后全部匹配；不含造图、授权和事后质量核验，不代表复杂布局、真实JD筛选或所有模型负载均可低于30秒。

验证边界：岗位菜单列出与收起已在真实页面验收；实际切换岗位及新版简历弹层空白退出完成隔离测试，尚未完成对应真实页面验收。所有真实性能测试均使用虚构简历，不联系候选人。
