# 招聘评估的上下文与 OCR 汇总约束

本轮初始化时先在上下文中读取指定岗位的完整 JD、评估规则及操作边界，并将其作为本轮固定依据。后续评估候选人时，不重复粘贴或复述这些内容，不自行改写、概括、删除或调整其含义。

需要生成上下文摘要时，必须完整保留当前有效的 JD、评估规则、操作边界及用户明确修改；候选人历史过程可缩减为结果和证据位置，不得用旧结论替代当前规则。

优先对 CLI 返回的完整长图进行一次 OCR，不为识别而预先切片，不对已被完整长图覆盖的截图或切片重复 OCR。提交前核对本人的截图与任务记录：已有任务则等待该任务，已有成功且输入一致的结果则复用；仅对尚未覆盖的必需材料发起新的 OCR。长图识别失败时按现有失败规则停止，不自动切片重试。

同一候选人的所有必需 OCR 结果成功返回并核验归属后，统一整理文字及来源，再进行一次完整评估。不要逐张截图反复评分，不把其他候选人的完整材料持续累积到当前评估输入中。

以上约束适用于 Agent 能控制的上下文整理行为，不代表已关闭宿主自动压缩或滑动窗口。若规则内容已缺失或无法确认完整性，应重新读取指定规则文件后再评估，不凭摘要、记忆或猜测补全。
