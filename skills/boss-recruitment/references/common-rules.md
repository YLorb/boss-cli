# 共用规则

真实页面读取、截图、滚动与操作均遵守[工具使用边界](tool-boundary.md)：只用公开 CLI，岗位切换脚本直连真实浏览器的旧许可已撤销。只读或验收不是换工具的许可；缺少 CLI 能力时停止受影响步骤并保留记录，不用内部模块或临时脚本继续。

执行约束以 [SKILL.md 的 SOP 执行约束](../SKILL.md#sop-执行约束必读) 为准。所有入口均必须遵守；只有使用者明确的特殊要求可在其指定范围内覆盖。不得把本文件单独使用成绕开入口 SOP 的另一套流程。

## 评估

使用当前使用者确认的 JD、维度、分值、门槛和独立准入条件；不内置本次大模型岗位的个人要求。每项分数引用具体简历段落，记录直接证据、未知项与置信度。同一成果重复出现只计一次，不按项目数量平均，不将关键词等同实际实现，不将可迁移潜力当作已具备能力。

截图逐段读到尾部；若截断、空白、身份不一致，标记证据不完整，不用未展示直接判定不合适。匹配结论是供人审核的初筛建议，不是录用决定。学校／竞赛若被使用者设为条件，单独记录 passed／failed／unknown 及证据；unknown 按使用者指定规则处理，没有规则则待确认，不自行拒绝。

## 身份与去重

沟通中使用姓名＋data-id＋目标岗位核对。搜索可使用经卡片、简历组件核验的 candidateId，并在取得会话后与 dataId 建立映射；推荐与其他入口不能直接套用该身份方案。同名、脱敏或卡片重排时，不能仅凭名字、旧序号认定同一人。无法唯一定位则停止该人的页面动作并记录待核对，不能试点不同卡片。人工接管／排除名单按本轮用户配置跳过。

## 人数、列表和停止

- 观察数 N：成功打开在线简历的不同候选人数。不合适和证据不足也计数；同人不重复计数。打开下一份前检查 N。
- 本轮开始保存对象快照、筛选条件与时间；逐人处理，循环内不刷新页面、不反复执行查询。新增未读留给下一轮。
- 达到 N、额度限制、明确列表耗尽或人工叫停时停止。操作错误默认停止；用户明确选择“仅查看、不联系，局部错误后继续”时，按[错误分级与继续条件](non-contact-continuation.md)处理，仅确认局部且继续条件全部通过时跳过当前对象。额度错误和列表耗尽需要页面证据，不能从空数组猜测。
- 达到 N 后在授权内完成当前人的记录；人工叫停或不明结果时仅保存，不继续副作用动作。
- 回执及时落盘：输入条件、来源、临时身份依据、已观察数、证据和分数、动作意图／结果、未决状态、下一位置。正式账本仅保存其支持的字段。

## 联系与消息（仅在获准时读取执行）

合适后先保存评估和触达意图；确认唯一身份及目标沟通岗位，再点击入口。确认沟通建立并得到会话联合键后去重入账、记录 PASS，核对并发送消息3。打招呼已发送完整消息3时不追加。只发了其他默认问候时，核对实际会话和消息后再按授权发送。

消息发送需保存正文、时间、会话和页面可见证据。超时／报错不能推断没有发送；不自动补发。消息3表示等待回复，不是附件 request=SENT。未回复保持等待，不主动催促，也不因此写 FAIL。候选人之后在目标岗位出现未读才进入收集 SOP。

常规搜索使用包含2026-10-20本地实现的CLI：先 greet "完整显示姓名" --check --json 核验唯一候选人及按钮，获得联系授权后去掉 --check 执行一次。在线简历已打开时同时核对卡片、简历和操作组件中的候选人 ID，不关闭后改点卡片。already-contacted 不重复点击；contact-confirmed 仅说明按钮变为“继续沟通”，不证明消息3或入账完成。点击后未确认必须暂停，不能补点或购买权益。旧安装或当前页面预检失败时停止并报告；本地离线验证不等于真实页面验收。

搜索触达的选岗分支、内嵌窗口实战计划及恢复步骤以[搜索 SOP](search-sop.md)为准。合适者触达前即保存待关联回执，失败也保留，取得真实会话联合键后才写正式 collect 账本；不得将回执业务阶段写成新的 collect status。
