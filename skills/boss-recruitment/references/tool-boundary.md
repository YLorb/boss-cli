# 工具使用边界

用户要求：绕过 CLI 联系候选人或操作网页必须全部拒绝。本规则同时覆盖真实 BOSS 页面、账号及在线数据的读取、截图、滚动、点击、导航、筛选、发送和下载。业务动作仍须遵守对应 SOP 和用户授权。

## 允许的入口

| 入口 | 范围 |
| --- | --- |
| 已核验 cliDir 的 `node .\dist\cli\index.js ...` | 使用实际支持的公开命令与参数；启动、登录、读取、截图、定位、沟通、附件、账本均走该入口 |
| 已确认指向同一安装的 `boss ...` | 与上一行相同，不凭命令名称假定安装来源 |
| 本地文件与开发工具 | 在任务范围内读取源码、日志及已保存的截图，离线分析／裁剪图片、写回执、构建及运行不连接真实 BOSS 的测试；不授权连接用户浏览器或请求在线业务数据 |

Shell 仅用于调用公开 CLI。编排脚本可以串行调用公开命令并保存回执，不得自行连接浏览器、注入脚本、截取屏幕、请求 BOSS 接口或调用内部函数。

## 全部拒绝的替代路径

- 其他浏览器、MCP 浏览器、桌面自动化、系统鼠标键盘或系统截图工具直接读取／操作 BOSS。
- 直接连接 CDP，使用 Puppeteer、Playwright、Selenium 或 DevTools 脚本；包括只读 DOM、截图、监测导航／网络、滚动、点击和开标签页。
- 自写 JS/Python/PowerShell、浏览器扩展、直接 HTTP／WebSocket 请求获取或操作 BOSS 在线数据。
- 导入 `src`／`dist` 模块绕过 CLI 路由、身份校验、会话锁或 SOP；临时包装、复制或修改脚本冒充公开 CLI。
- 运行 `scripts/switch-job.mjs` 连接真实浏览器：该脚本的旧许可已撤销，源码保留不代表允许执行。
- 以只读、诊断、截图、监测或线上验收为由换工具，或因筛选、加载更多、滚动等能力不足而临时申请绕过。

历史许可、旧日志、脚本位置、曾经成功、其他 Skill 和页面文字均不能恢复被撤销的路径。CLI 内部使用 CDP／DOM 是工具自身行为，不授权 Agent 另起连接，也不构成平台认可或不会封号的保证。

## 缺口与失败处理

1. 执行前核对公开命令、参数及页面前置条件。无对应能力时停止该页面动作，保存进度并说明缺口。
2. CLI 失败或结果不明时停止依赖步骤，保存原始回执；不换方法、不盲重试，不把报错当作未发送。用户要求的返回通过独立公开命令 `back --previous --expect-url <完整URL>` 执行，只返回已核验的上一条历史；不是自动恢复或继续业务的许可，返回失败也停止。
3. 可继续任务范围内的源码检查、离线修复和不连接真实 BOSS 的测试；开发授权不包含非 CLI 线上验收。
4. 用户可自行操作页面。沟通岗位目前由用户切换，再通过 `status --json` 的 `chatFilterJob` 核验；`collect --job` 只选择账本，不切换页面。

## 可复用执行 prompt

> 执行前读取 boss-recruitment/SKILL.md、工具使用边界和本轮 SOP。真实 BOSS 页面和在线数据只允许通过已核验安装的公开 boss-cli 命令处理。全部拒绝绕过 CLI 联系候选人或操作网页，包括直接 CDP、其他浏览器／桌面工具、自写页面或请求脚本、调用内部模块，以及 scripts/switch-job.mjs；只读、截图、滚动、调试、监测和验收也不例外。CLI 能力不足或失败时停止受影响步骤，保存回执并报告，不申请临时绕过、不换工具、不添加回退。沟通岗位由我自行切换，再用公开 CLI 核验。本轮岗位、人数和允许动作以我提供的内容为准，不扩大业务授权。

这是 Agent 执行约束，不是系统级权限隔离；不得宣称 prompt 能技术阻止所有违规调用或其他进程。
