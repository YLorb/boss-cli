# 可选导入

不是核心SOP，也不是boss-cli内置能力。使用者提供系统地址、认证方式、接口文档和岗位映射；不沿用原手册的内部IP、账户或岗位UUID。凭据在使用者环境中读取，不写入Skill、回执或聊天。

收集阶段先下载本地并核验文件、bytes、SHA-256。完成本轮后，在上传授权范围内逐份导入并回读；用户叫停不继续上传。未经授权不提交简历给第三方。

原系统曾用 `/api/v1/candidate-imports?positionId=...` 上传、`/api/v1/candidate-imports/{id}` 回读。这只是旧系统接口形态，不适用于任意HR系统。根据对方文档适配，不猜接口或沿用旧岗位ID。

每份保存系统返回ID、岗位、文件哈希、状态与版本；回读核验岗位和文件名。READY不等于解析、评估或建档完成。超时或结果不明先查询现有记录，不盲重传；幂等规则由目标系统决定，CLI未实现上传适配器。
