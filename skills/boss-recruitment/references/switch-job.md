# 岗位切换：必须按本规范执行

脚本位于 **CLI仓库** `scripts/switch-job.mjs`，不在Skill目录中。需要包含该脚本的交付版本；若下载的旧版本没有它，停止并更新到交付者提供的版本，不临时生成替代点击脚本。collect --job只选择账本，不切换页面。

## 前置条件

1. 已按[启动规范](start-and-use.md)使用boss-cli完成Chrome启动及登录核验，CDP可连接；只保留一个BOSS标签页，且已经在 `/web/chat/index` 沟通页。脚本不启动浏览器、不登录、不导航、不选第一个标签兜底；连接失败也不得改成自行启动Chrome。
2. 本轮目标岗位已由用户指定，尚未采集本轮未读快照；切换岗位属于开轮准备，不得在逐人循环中反复切换。
3. 其他页面操作已结束，串行调用。不要在用户同时切换岗位时继续自动操作。

## 调用顺序

在CLI仓库根目录执行：

```powershell
node .\scripts\switch-job.mjs --list --cdp-url 'http://127.0.0.1:53470'
```

该命令展开岗位下拉，返回当前岗位before和实时options，不改变选中岗位。**从返回值中取得目标完整label**，包括城市等区分信息，不猜名称、不只传关键字、不把关闭岗位当在招。同名文案不唯一则停止，请使用者明确页面对象。

```powershell
node .\scripts\switch-job.mjs --job '从options取得的完整label' --cdp-url 'http://127.0.0.1:53470' --timeout-ms 10000
```

只有退出码0、ok=true且返回job与目标完整label相同，才进入下一步。已经选中时changed=false，不重复点击。切换后再按收集SOP读取一次起始未读快照，核对返回岗位与目标JD一致；脚本成功仅确认下拉选中，不证明候选人列表已经加载或每条归属正确。

## 强制边界

- 仅操作 `.chat-top-job` 范围内岗位下拉；不操作分类、候选人、消息、附件或推荐／搜索筛选。
- `--list`与`--job`二选一。`--cdp-url`默认本机53470，不读取Skill配置或CLI端口环境变量，非默认端口必须显式传入。`--timeout-ms`为单步等待／协议超时，不是整命令预算。
- 不支持旧临时脚本的第二个分类位置参数。普通分类使用已有CLI支持的入口；“新招呼”等未封装分类不能用此脚本假装已设置，应报告缺口或按用户明确的特殊要求另行处理。
- 未找到、重名、关闭／禁用、错误页面、多标签、校验超时均失败并返回非零码。不得忽略错误继续，不改成模糊匹配、全页面任意li点击或自动重试。
- 超时意味着切换结果未确认，不代表未点击。保存完整JSON错误、目标label和实际状态，停止依赖该岗位的动作；无获准特殊要求不自行绕过。
- 返回字段和错误写入本轮回执；正式会话、发送、收件继续使用CLI及各自SOP，不将DOM权限扩展到其他动作。

验证范围：隔离Chrome模拟页面验证参数、实时列出、异步切换确认、同岗位不重点击、重复／模糊／禁用项拒绝、超时停止和错误页面拒绝；不代表所有BOSS账号当前DOM均已实测。页面结构不符合选择器时直接报告，不添加备用路径。
